# FocusFlow ⏱️

A minimalist, responsive Pomodoro timer web application built for quick deployment and distraction-free study or work sessions.

## ✨ Features

* **Three Session Modes:** Switch between Pomodoro (25 mins), Short Break (5 mins), and Long Break (15 mins).
* **Dynamic Tab Title:** Timer countdown updates directly in your browser tab title.
* **Lightweight & Fast:** Built entirely in a single file using Tailwind CSS and vanilla JavaScript with zero backend dependencies.
